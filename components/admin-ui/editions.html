Editions

You are using Keeplane Open Source. It works fully on its own.

Open Source includes

  • Projects, onboarded with init in Keeplane's CLI
  • Workflows and agents
  • Models and routing, with developers' own keys
  • Data classes and personal-data detection
  • The audit add-on
  • Sign-in with username and password or single sign-on
  • Keeplane's CLI for developers

Enterprise adds

  • Organization-wide rules
  • Teams and access control, with groups mapped from your provider
  • Governance across all teams
  • An outcome report across teams

How to get Enterprise

Notes in the web UI

One plain line, shown once, where you reach something only Enterprise does.

No feature moves from Open Source to Enterprise. The Open Source license stays Apache 2.0.
