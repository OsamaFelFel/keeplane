# 10 October 2026 — Secret-backed gateway database URL

The earlier [baseline diagnostic](2026-10-10-production-secret-gap.md) found a password-bearing PostgreSQL URL in the local chart's rendered ConfigMap. A follow-up tested the supported alternative instead of treating the chart as blocked: keep `${TRIAL_DB_PASSWORD}` in the URL and supply that variable from a Kubernetes Secret through the upstream chart's `extraEnv` value.

The [plain-English cases](../gateway-secret-cases.md), [Docker/Helm verifier](../test_gateway_secret_binding.py) and [three passing observations](2026-10-10-gateway-secret-binding.json) use pinned agentgateway 1.6.0 and disposable PostgreSQL. The gateway became ready with the environment-supplied password. An otherwise identical gateway with the wrong value exited with PostgreSQL authentication failure. The Keeplane managed-chart render contained the placeholder and a `secretKeyRef` in the gateway Deployment, without the fixture password in its ConfigMap. The verifier removed its Docker project.

The [isolated Kubernetes verifier](../test_gateway_secret_kind.py) and [passing result](2026-10-10-gateway-secret-kind.json) then installed the exact pinned upstream Helm chart in a temporary namespace of the separate Calico kind cluster. One gateway replica became Ready and its health endpoint returned 200. Its live ConfigMap contained the placeholder, the Deployment referenced `gateway-db-credentials/password`, and the disposable password was absent from the ConfigMap. The verifier removed that namespace. Neither product preview changed.

This closes the **tested chart secret-delivery gap** for a PostgreSQL password. The current `deploy/local/values.yaml` intentionally still embeds its disposable password and must never be copied as release values. A release package needs an operator-supplied Secret, namespace RBAC, storage encryption policy, password rotation and restart behavior, backups, production PostgreSQL, two-replica cold startup, a customer-installable gateway artifact and full installation regression. The release gateway remains unselected.
