# 10 October 2026 — protected customer-run gateway trial

**Edition:** Open Source. **Scope:** isolated local kind trial, not a release gateway selection.

Keeplane now runs a protected app in `keeplane-existing` while the supplied agentgateway stays installed independently in `supplied-gateway`. The Keeplane namespace has one app Deployment, one private ClusterIP Service and two local trial PVCs; it has no gateway Deployment. The app uses the same first-admin account flow, React screens and Django account routes as the managed preview. Its records are separate. Port 13001 is available only while a test or operator opens a loopback port-forward.

The [plain-English cases](../existing-gateway-cases.md), [Kubernetes cases](../kubernetes-cases.md) and [chart cases](../chart-package-cases.md) are reusable. The [confirmed full run](2026-10-10-protected-existing-confirmed.json) passed **48/48 suites and 287/287 top-level case records**. It includes seven Helm packaging cases, eight kind gateway cases, four existing-gateway preflight cases, and three protected existing-mode cases. The latter include **21/21 account verdicts**. A no-key model set up through Keeplane answered through the supplied gateway; a gateway-only model was refused by Keeplane. The supplied gateway retained its pre-existing fixture and the managed gateway's catalog remained separate.

The [existing-mode Chromium run](../../browser/runs/2026-10-10-protected-existing-final.json) passed **15/15** Users, Data Classes and Audit browser cases, including desktop and 320px checks. The existing app was Ready after the full run, its Service remained ClusterIP, and both PVCs were Bound. Docker on port 3000 and managed kind on port 13000 still returned HTTP 200 for first-admin sign-in and gateway-ready health. Their original Data Classes modes were restored. The managed kind cloud-provider test key matched its original private value after key rotation.

The [first broad run](2026-10-10-protected-existing-full.json) passed 47/47 then-listed suites with 284 case records before the new existing-mode case was added to the reusable runner. The [next full attempt](2026-10-10-protected-existing-final.json) passed 47/48 suites; the new suite stopped before producing cases while opening its temporary local port-forward. A direct retry and the [focused runner retry](2026-10-10-protected-existing-portforward-recheck.json) passed. We removed the extra local-port bind precheck; the confirmed 48-suite run then passed. The failed result is retained rather than described as an app failure.

This closes a **local no-key customer-run gateway trial**, not ST5 release acceptance. Shared provider-key delivery is still open: Keeplane saves a key file on its own namespaced PVC, while the separately installed gateway has no access to that volume. The exact release gateway artifact, production account and audit stores, full network boundary, project-class bypass resistance and the image license gate remain open. A local mock answer does not prove a real cloud subscription.
