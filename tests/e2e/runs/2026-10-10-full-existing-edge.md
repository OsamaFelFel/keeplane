# Customer-run gateway behind the protected TLS edge

The [plain-English cases](../full-existing-edge-cases.md) and [repeatable verifier](../test_full_existing_edge.py) ran the pinned upstream agentgateway chart separately from Keeplane's existing-gateway chart on the isolated Calico kind cluster. A generated certificate, first-admin password and gateway keys were used only in temporary files and Kubernetes test Secrets. The verifier removed both disposable namespaces and its port-forward. The regular Docker and kind previews were not redeployed.

The [confirmed machine result](2026-10-10-full-existing-edge-confirmed.json) passed **5/5 cases**. Keeplane's own namespace contained only its app Deployment. The gateway preflight succeeded, HTTPS sign-in and identity worked, and Keeplane registered a local fixture model on the customer-run gateway and received its answer. After a customer-owned ingress policy was applied to the gateway, the app remained connected but an unrelated pod timed out before it could call the gateway. Keeplane's public TLS address redirected `/v1/models` to sign-in instead of publishing a gateway route.

The [initial run](2026-10-10-full-existing-edge-first.json) and [diagnostic repeat](2026-10-10-full-existing-edge-diagnostic.json) each failed model setup. They tried to approve `customer-fixture`, a gateway-only model that Keeplane had not registered; the diagnostic showed the app could reach the gateway but could not verify that model's definition. The final run used Keeplane's supported registration path for `customer-managed`. The [intermediate passing run](2026-10-10-full-existing-edge-registered.json) is retained; the final run tightened the public-route assertion to require the observed 302 redirect.

The customer's network policy was installed after Keeplane's preflight Job, so this result does **not** prove a protected installation from its first request. The release setup still needs a policy that admits the preflight Job safely, plus default-deny egress, provider-path control, project-bound identity and class enforcement, production storage, certificate operations and a customer-installable gateway artifact. The release gateway remains unselected.
